录音
录制PCM格式的数据！！！
需要创建文件，写入文件！！！
录音标识：flag 
> 录制的过程：判断是否可以写入，收集写入的数据，按照偏移量写入文件

- 方式一：

whilte(flag){
offset:文件写入偏移**量**(不能覆盖)
length:每次写入的**量**
**下次写入的偏移量 = 当前偏移量 + 当前写写入的量**
}
> 录制 = 收集声音 +  写入文件 

> 停止 = 停止写入文件 + 停止收集声音

播放

- 方式二：
   - renderModel.on('writeData',(buffer)=>{
      - 自己判断是否停止
   - })
> 播放 = 读取文件 + 播放声音

> 停止 = 停止读取文件 + 停止播放声音

停止的细节：
1.切换文件需要先停止，再重新播放文件
2.停止的判断条件 ：渲染的size>播放文件最大尺寸?
3.停止只能在播放器创建好 + 状态机===running时停止

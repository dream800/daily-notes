样式语法：
1.样式分类：通用的样式 + 组件自带的
2.样式的值：固定的值，或者枚举 ，让值变的有意义  eg:听懂扣1，不懂扣2  1和2没意义  枚举以后就可以通过枚举的类型看出意义 

PX/VP/FP/LPX
 PX固定大小像素
vp虚拟像素  1vp=3px
fp和vp一样  只不过改了系统字体，用fp的会变化 （当前不支持只改字体）
lpx  类似于REM  可以设置屏幕基准值，然后给定值适配 (老的项目迁移或单类型设备的开发 )

Image 
  1.自建目录  (assets)  -> /assets/a.png
  2.用网络图片   Image('htpp://xxxxxx')       模拟器和真机需要开网络权限
  3.资源图片：media     $r('app.media.a')
  4.rawfile:    $rawfile('a.png')
  5.系统内置图标  :  $r('sys.media.ic_public_voice').fillColor(Color.Red)
  6.下载SVG（ iconfont / 华为官网 ）

Color + String
先声明再使用
$r('app.media.Color')  
国际化：创建中英文两个字段，切换语言时，文字会自动切换

styleStates 
{
1.normal   ->   初始状态：如果没有或者样式上不包含，触发其他状态就回不去了！
2.pressed  ->  按压下的状态
3.disabled ->  禁用，会在原来的颜色上蒙层
4.focused  ->  聚焦：预览器和模拟器tab切换才能触发
5.selected  -> 选中下的样式，不常用
}

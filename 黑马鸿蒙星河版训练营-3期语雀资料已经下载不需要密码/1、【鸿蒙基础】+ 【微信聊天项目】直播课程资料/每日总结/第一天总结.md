安装编辑器
安装环境：
1.SDK  ->  按照指定目录安装  -> 写的代码如何运行在鸿蒙环境
2.nodejs -> 不要使用自带的，用编辑器安装  -> 第三方包运行的环境
3.ohpm -> 不要使用自带的，用编辑器安装 -> 类似于npm，是第三方包下载的管道，依赖nodejs环境
具体安装建议参考视频
组件说明：
一个页面可以理解成一个组件
页面构成：
1.@Entey 或者 @Preview
2.@Component 
3.struct 组件的名称 {
    4.构建函数
    build(){
注意点：
1-可以没有内容
2-有内容必须是一个容器组件

    }
}
页面创建会在main-page.json5形成路由，有映射关系，如果删除页面建议删除对应的关系，否则报错（不要复制文件，不会自动帮我们创建路由）
组件构成:
和页面差不多，可以没有@Entry修饰符
组件可以导出，在其他页面导入使用

开发页面：
口诀：头顶天，脚踩地！  (从上到下，从左到右，从外往里，从大到小)
布局 - 线性布局 （要么横着排列要么竖着排列）
Row 横向排列 纵向剧中 内容超出不会显示滚动条
Column 垂直排列 横向剧中 内容超出不会显示滚动条
主轴：排列方向的轴  
设置主轴的对齐方式：.justifyContent(FlexAlign.Center)  可以起始位置，可以剧中，可以结束位置对其

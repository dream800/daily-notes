- 语音转文字
   - 引擎：asrEngine
   - 创建引擎：复制参数
   - 准备监听参数：onResult
   - 原理就是不断读文件，将buffer写入引擎的缓冲区，监听到有内容就会转化
- 文字转语音
   - 创建引擎：复制参数
   - 引擎: ttsEngine
   - 创建- ttsEngine.speak(text,参数)
- 语音波峰计算
   - 1bit 0 1
   - 1byte = 8bit  00000000 ~ 11111111 有256种组合
   - 16进制，每两位也有256种组合，所以可以将buffer转为16进制表达
   - 16进制的buffer最大值是32767  2*15次方，有一位是符号
   - 将buffer转为int16的数组，每两位代表1个字节
   - 双重for循环，累加求平均值 /32768  = 0~1 ,再 *容器的高度

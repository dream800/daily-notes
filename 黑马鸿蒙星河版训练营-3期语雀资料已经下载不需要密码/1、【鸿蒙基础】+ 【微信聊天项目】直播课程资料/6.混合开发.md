> 混合开发 = 鸿蒙 + web
> 目标：
> 1.鸿蒙应用的代码能够控制web页面
> 2.web页面能够控制鸿蒙应用
> 核心webview的使用：[API参考文档](https://developer.huawei.com/consumer/cn/doc/harmonyos-references-V5/js-apis-webview-V5)

- 鸿蒙应用控制web应用
> 直接runJavaScript，运行web页面的方法

```arkts
import { promptAction } from '@kit.ArkUI'
import webview from '@ohos.web.webview'

@Entry
@Component
struct WebCase {
  controller:WebviewController = new webview.WebviewController()
  aboutToAppear(): void {

  }
  testFn(){
      promptAction.showToast({
        message:'h5让我弹的'
      })
  }
  build() {
    Row() {
      Column() {
        Button('变！')
          .onClick(()=>{
            this.controller.runJavaScript('changeText()',(err,result)=>{
              if(err){
                promptAction.showToast({
                  message:'err:'+err.message
                })
              }
              if(result){
                promptAction.showToast({
                  message:'success:'+result
                })
              }
            })
          })
        Button('注入事件')
          .onClick(()=>{
            this.controller.registerJavaScriptProxy({
              objKey:()=>{
                this.testFn()
              }
            },'objName',['objKey'])
          })
        Button('刷新')
          .onClick(()=>{
            this.controller.refresh();
          })
        Web({
          src:$rawfile('test.html'),
          controller:this.controller
        })
          .javaScriptAccess(true)
      }
      .width('100%')
    }
    .height('100%')
  }
}
```

- web应用控制鸿蒙页面
> 注入JavaScript脚本，refresh后生效，web页面可以调用执行

```arkts
<!doctype html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, user-scalable=no, initial-scale=1.0, maximum-scale=1.0, minimum-scale=1.0">
    <meta http-equiv="X-UA-Compatible" content="ie=edge">
    <title>Document</title>
</head>
<body>
        <h1>你好</h1>
        <button onclick="sendMsg()">发消息</button>
</body>
<script>
    function changeText(){
      document.querySelector('h1').innerText = '你不好！'
      return 'change success'
    }
    function sendMsg(){
        objName.objKey()
    }
</script>
</html>
```
